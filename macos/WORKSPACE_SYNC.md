# Mac 跨裝置同步 — SYNC-001 候選

設定 → 資料 → 跨裝置同步使用原生 SwiftUI 元件。Mac 的 AtlasClient 仍只連本機 loopback；共用 Go 引擎透過可信任 VPS 的 HTTPS 執行同步，目的端使用自己的 Keychain 主金鑰重新加密。Mac 休眠時不承諾持續運行，喚醒後可接續增量同步。

正式入口提供一次性配對、可選 Key 授權、立即同步、裝置清單與撤銷、中斷連線，以及保留雙方修改的衝突檢視。解析網址時拒絕帳密、路徑、查詢及非 HTTPS。配對碼只留畫面記憶體，離開即清除；不進偏好設定或日誌。

共用引擎保留完整作用域、持久游標、歷史與衝突資料。採用同步中心版本前重新取得目前記錄，選擇以完整本機內容雜湊核對，不以畫面摘要覆寫後來修改。斷線或撤銷保留本機資料。同步本身不呼叫模型。

原 78 個核心測試、每架構 74 張靜態圖及 14 張動畫 frame 全部保留。新增 3 個配對輸入測試、1 個真正的雙 packaged engine／Keychain／HTTPS 整合測試及每架構 2 張同步設定實圖；新候選目標為 82 核心／76 靜態圖各架構，共 152 靜態圖＋28 frame。原串流字數、雜湊、閱讀位置、25 秒與 120 秒限制不減。

整合測試使用隔離資料目錄、獨立 Keychain 主金鑰與已有的臨時可信 TLS fixture；只轉送公共同步路由到另一個真實引擎，不轉送管理員 API。透過原生 AtlasClient 驗證配對、兩端修改／衝突、目的端真實本機合成推論、完整訊息同步、重啟接續與撤銷後資料保留。它不連真實供應商，也不代表目標 VPS 或實體 M2 已驗收。

新 HEAD 的同 SHA 九項 Actions 與實圖未完成前仍為候選。Android 尚無同義原生呈現的研究／對話紀錄會完整保存，不能因此宣稱三平台所有功能已互通；研究排程、未知站點、Reflection 與真實性願望清單仍各自待完成。
