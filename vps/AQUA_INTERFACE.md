# Aqua 水光介面

在右上「設定 → 一般 → 顯示外觀 → 介面風格」選擇「Aqua · 水光玻璃」，再從「背景插畫」選擇Kotoha／伊蕾娜原圖或各自的Q版。預設保留經典介面；Aqua初次選用Kotoha原圖。背景、介面、深淺主題、重點色與減少動態效果是此瀏覽器的非敏感偏好，不啟用研究、同步或推論。

四張素材依D-020採用使用者指定的兩張JPEG原檔，以及先前生成的兩張透明Q版。原圖bytes完整保留；Q版以無損WebP保留1254×1254全部RGBA像素與透明度。完整hash、尺寸及來源說明見`assets/aqua-wallpapers-v1.json`。兩張原圖分別135772／422004bytes，Q版1560556／1528248bytes；只讀取所選圖片。原花園圖片已移除，不再作為預設或退回背景。

Aqua沿用正式頁面、欄位與對話／Provider草稿，切換不重新載入資料、重建表單或改選模型。Playground、Providers、Models三主導航與右上設定保持。參考使用者Aqua Full Demo與https://nozoki.soki.moe/的玻璃氛圍，桌面使用浮動工具列／側欄，手機保留安全區、48px操作區和浮動底導覽；長名稱與200%文字可換行。原圖滿版裁切，Q版保留透明底並置於畫面右下，聊天文字使用獨立可讀底色。

正式來源為`ui_aqua.go`、`ui_css_aqua.go`。樣式與圖片只在選用Aqua後由同來源受認證路徑讀取，不熱連結外部圖片／字型。圖片支援ETag、HEAD及Range，登入和跨站限制先於快取，cache為private。偏好只接受四個既有ID，非法值回Kotoha；儲存不可用時仍可操作。缺少圖片或玻璃濾鏡時保留可讀底色；樣式讀取失敗則明示改回經典介面，再次選取可重試。
