# Aqua 水光介面

在右上「設定 → 一般 → 顯示外觀 → 介面風格」選擇「Aqua · 水光玻璃」。預設保留經典 Mac 風格。介面、深淺主題、重點色與減少動態效果是此瀏覽器的非敏感偏好；不啟用研究、同步或推論。

Aqua 使用既有正式頁面、欄位與對話／Provider 草稿，切換不重新載入資料、不重建表單或改選模型。Playground、Providers、Models 三主導航與右上設定保持。桌面以浮動工具列、側欄與玻璃卡片呈現；手機保留16px內容邊界、安全區、48px操作區和浮動底導覽。長名稱與200%文字可換行，細節頁沿用原捲動與返回。

參考使用者既有 Aqua Demo／Full Demo 的水光視覺及 https://nozoki.soki.moe/ 的玻璃氛圍。原型大圖、雙層導航與小字已重新安排，不採用其靜態餘額、性能或假健康狀態。背景為另行生成的原創花園插畫，以257786bytes WebP隨單binary供應；樣式與圖片只在選擇Aqua後由同來源受認證路徑讀取，沒有外部圖片、字型或分析請求。缺少圖片或不支援玻璃濾鏡時仍保留可讀底色；樣式讀取失敗則明示改回可操作的經典介面，再次選取可重試。經典介面不下載或匹配Aqua樣式。

正式來源為 `ui_aqua.go`、`ui_css_aqua.go`，圖像及完整生成提示見 `assets/aqua-garden-v1.json`。WebP原檔直接嵌入，第一次Aqua圖片請求才計算快取雜湊，受相同登入／跨站限制；ETag、HEAD及Range仍先驗證登入，cache為private。
