# 對話紀錄工作區

Playground 的「對話紀錄」沿用原有對話、完整歷史、搜尋及匯出。可以搜尋標題、模型或已保存的訊息內容，依使用中／封存／全部與目前模型篩選；不發出模型推論，也不自動加入、改選或移除模型。

卡片分開呈現名稱／置頂、供應商與完整連線、訊息預覽、訊息數與更新時間。更新時間使用伺服器提供的 updated_at／created_at，以瀏覽器時區顯示；不是推論效能或可用性證據。清單中的長名稱與預覽各顯示最多兩行，開啟後仍可查看完整名稱；完整內容仍可分頁閱讀、搜尋及匯出。

## 搜尋與讀取

- 新搜尋、篩選與下一頁等待時，保留上次成功的清單，明確標示仍在讀取。失敗不清空、不將舊結果冒充新搜尋結果。
- 讀取失敗可「重新讀取對話紀錄」。下一頁失敗保留原 offset 與已讀列，只重新讀取該頁，依對話 ID 避免重複列。
- 新搜尋或離開工作區會取消過期的讀取。中文輸入組字完成後才搜尋；Enter 可立即搜尋，清除搜尋保留其他篩選。
- 沒有符合結果與尚未讀取成功各自呈現，不拿錯誤當作空資料。

## 整理對話

- 改名、置頂與封存沿用原 session API、同一對話 ID 與 revision CAS。每個對話同時只送出一筆變更，關閉再開啟也不會重複提交。
- 送出名稱後仍可繼續編輯新草稿；成功回應、重新整理清單及關閉重開不覆蓋後來輸入的內容。草稿只留在當前頁面的記憶體，不寫入雲端或瀏覽器永久儲存。
- 「變更已保存，但清單讀取失敗」只提供唯讀重試，不重送已確認的變更。
- 網路／回應不確定或版本衝突時，先「讀取保存狀態」。讀取實際保存內容（包含已封存的對話）並保留名稱草稿，之後由使用者明確決定是否再儲存；不自動重播寫入、不猜測先前操作是否成功。
- 使用先前對話前，再核對目前仍可選的精確 Provider／Account／Credential／Model／Group／Endpoint；封存或無相同可選連線的紀錄仍可檢視與匯出。
