# 通用部署試跑指令

這份指令供使用者自行操作，或請任何能執行 Linux 命令的工具協助試部署。Muse 只是其中一個可測試的環境；ModelAtlas 的開發與維護仍在原專案繼續，不由部署工具接手。搭配完整安裝包與 `DEPLOY_AND_BACKUP.md` 使用，不要把包內舊公開版本號當成本次來源 SHA。

```text
請依附件 DEPLOY_AND_BACKUP.md，試著把 ModelAtlas 部署成我能登入的 HTTPS 服務。這次只驗證部署；不要接手專案開發或為目前平台另外分叉程式。

這是通用 Linux／容器部署，Muse只是現在的執行環境。請直接處理可做的工作；先檢查 CPU架構、持久磁碟、程序常駐／supervisor及HTTPS入口，選Compose或免root binary。若平台不能常駐或重建不保留磁碟，明確說出缺少條件，不把短期預覽當24/7服務。

使用附件已校驗的AMD64／ARM64完整套件，程式固定commit為00b6a67ef112c86b750a588503de7b05bfa0bb12。驗根目錄和包內SHA256SUMS、bundle-check及version，再啟動。不要自行換latest／main，也不要拿不含新命令的舊公開Release替代。

資料與私密設定放持久目錄／volume，程式目錄可替換。保留同一master key、管理密碼及資料庫；原SQLite不放雲端同步掛載。用真正的HTTPS ingress、原認證與SSE，給我可使用的網址。

先完成啟動、認證、HTTPS／SSE與重啟後資料仍在的部署測試。雲端備份的設定與還原步驟都已寫在說明書；若我尚未指定雲端目的地或沒有要求這次設定，就保持備份排程關閉，回報尚未設定，不要因此卡住部署，也不要自行借用別的帳戶。

只有在我要求接上備份且已指定目的地時，才繼續備份章節：使用專用rclone設定與crypt加密，需要雲端登入時讓我在正式介面完成授權，並在我真正另存復原材料後才確認key recovery。做第一次備份、真正回讀及隔離還原；找回非敏感驗收註記或原歷史後，再依我的需求設定排程。不自動刪除DB、volume、raw歷史或雲端版本；保留last-good與失敗紀錄。

更新及回退照說明使用一致快照、離線副本preflight與匹配schema的舊版還原，不重建key、不清資料。不要因為要上線而關掉認證、Host／Origin檢查或備份回讀驗證。

完成後回報：HTTPS網址、部署模式、實際來源SHA、state／volume位置、常駐方式、重啟與SSE實測結果，以及備份是否設定、是否真的完成回讀與還原。未做的項目明列未做；密碼／master key／OAuth token只保存在私密位置，結果報告只說其保管位置，不貼內容。

部署驗收完成可回報試部署成功，但不要把未設定的備份或短期入口稱為已完成異地復原或24/7服務。環境不支援必要條件時，列出實際缺口；其他不依賴該條件的工作繼續完成。
```
