## 邊界

這是已存在 Mac 能力的 VPS 接線，不代表所有 Master Spec／所有站點私人 adapter 已完成。未使用使用者私人 Key 測試 HJMAPI 推論；上游仍可能回應限制或錯誤。公開 schema 相容不等於私人帳戶 API 相容。路由／fallback／自動 Key 輪替／Gateway 維持 future-only。

保留原十四個 Browser 流程，新增搜尋選模與 Mac 對齊工作流。舊雙欄的卡片幾何斷言依新版單欄調整為同左緣、同寬、依序不重疊及至少 48px，不刪除排列驗證或既有資料斷言。Android UI 尚待下一片；本輪僅移植 Mac 已驗收的測試驅動修正。

部署維持單 Go／SQLite，沒有新增正式依賴。參見 PLATFORM_DEPLOY.md、DELIVERY.md；更新需保留既有 DB 與相同 master key，不能把測試 fixture 當正式資料。
